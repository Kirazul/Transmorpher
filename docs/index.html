What Transmorpher Covers

Everything you need to customize your character's appearance, from gear to the world itself.

Gear Transmogrification
Preview items by slot and subclass, apply hidden-slot looks, browse enchants, open Wowhead links, cycle donor items sharing the same appearance, and recolor textures per slot with tint and glow controls.
Character Morphing
Switch to any race model with male and female variants, apply creature display IDs, resize from 0.1x to 10.0x, save favorites with rename and reorder, and undo with a 40-deep history stack.
Creature and Mount Morphs
Morph mounts with All, Ground, and Flying filter. Browse over 15,000 creature displays with NPC, Boss, and Normal classification. Per-mount recolor via BLP texture resolution with persistent storage.
Pet Morphing
Companion pets with quick apply. Hunter pets from curated families or all creatures. Dedicated scale input from 0.1 to 10.0 with resize button. Includes warlock demons and water elemental.
Loadouts
Capture full appearance presets: gear, enchants, morphs, pets, scale, title, sheathe positions. Bind to talent specs, auto-apply on switch, export and import as portable TM1 strings.
Form Morphing
13 form groups: Bear, Cat, Moonkin, Tree, Travel, Aquatic, Flight, Ghost Wolf, Metamorphosis, Shadowform, and DBW proc forms. Auto-detects available forms from shapeshift bar.
Spell Visuals and Auras
Remap spellbook spells to other visuals. Conditional aura-triggered swaps. Persistent aura browser to permanently wear spell effects across morphs, forms, zoning, and relogs.
Barber Controls
DBC-driven skin tone, face, hair style, hair color, facial hair. Per-region free-RGB tint with Solid, Gradient, Rainbow, and Two-Tone modes. Full saturation, brightness, contrast, and hue sliders.
Item and Creature Recoloring
Per-slot item recolor via donor textures. Creature and mount recoloring with BLP path resolution. Texture capture mode for discovering recolorable surfaces. Account-wide persistent storage.
Damage Text Colors
Customize 8 categories: Damage, Damage Crit, Healing, Healing Crit, Miss/Dodge/Parry, Absorb, XP, and Honor. Per-category rainbow mode with speed slider. Global size slider.
World Presentation
Client-side time of day, fog override with color and start/end sliders, far clip distance, smooth textures with bias, 21 render analysis toggles, and distance culling with master slider.
Optimization
Smart visual filtering with 15 spell part categories, per-target-group control, class filters, raid tier protection for T7 through T10 and VOA, protected spell list, and unit suppression.

Installation

Get up and running in four steps.

Download

Grab the latest release from GitHub.

GitHub Releases

Addon Folder

Copy the Transmorpher folder into your WoW addons directory.

Interface/AddOns/Transmorpher

DLL File

Place dinput8.dll and Skia.dll next to Wow.exe in the main WoW folder.

World of Warcraft/dinput8.dll

Launch

Start the client and type /morph or click the minimap button.

/morph

Multiplayer Sync

Share your appearance with other Transmorpher users in real time.

Peer to Peer World Sync
Optional sync via RAID, PARTY, GUILD, and WHISPER channels. Automatic peer discovery, state broadcasting, chat filtering, vehicle forwarding, and suppression mode. No chat spam.
Smart Filtering
Control what gets shared. Suppress notifications, configure peer names, toggle self visibility. Your own morphs stay active even with remote sync disabled.

Quick Commands

Essential slash commands for power users.

/morphToggle the main window
/morph resetReset all active morphs
/morph morph <id>Morph to creature display ID
/morph randomRandom creature morph
/morph undoUndo last character morph
/morph fov <20-350>Set camera field of view
/morph exportExport TM1 loadout string
/morph import <str>Import TM1 loadout string

Aliases: /vm and /Transmorpher
